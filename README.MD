# Trippy Match 🃏

A simple memory matching game built with HTML, CSS and JavaScript.

The goal of the game is to find all matching pairs by flipping the cards and remembering their positions.

## Features

- 20 cards
- 10 matching pairs
- Cards are randomly shuffled at the start of each game
- Responsive design
- Animated images
- Built with vanilla JavaScript

## Technologies Used

- HTML5
- CSS3
- JavaScript

## How to Play

1. Click on a card to reveal it.
2. Click on another card.
3. If both cards match, they remain visible.
4. If they do not match, they are hidden again.
5. Find all the matching pairs to win the game.
